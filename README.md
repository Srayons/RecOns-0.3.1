## 🚀 快速开始

### 1. 下载语音模型

本软件基于Vosk本地语音识别，需要先下载识别模型：

- **标准版（推荐，识别准确率高）**：`vosk-model-cn-0.22` (约1.3GB)
  下载地址：https://alphacephei.com/vosk/models/vosk-model-cn-0.22.zip

- **轻量版（速度快）**：`vosk-model-small-cn-0.22` (约40MB)
  下载地址：https://alphacephei.com/vosk/models/vosk-model-small-cn-0.22.zip

> 对识别准确率要求高请下载标准版，追求启动速度选轻量版即可。  
> 软件支持60+其他语言（英语、粤语、日语、韩语等），同页面下载对应模型即可。

### 2. 安装模型

将下载的zip压缩包**解压**到软件根目录的 `models` 文件夹中，结构如下：
```
SubtitleRecorder/
├── models/
│   └── vosk-model-cn-0.22/   ← 解压后的模型文件夹
│       ├── am/
│       ├── conf/
│       └── ivector/
├── recordings/               ← 录制输出目录
├── SubtitleRecorder.jar
└── run.bat
```

### 3. 启动软件

**Windows用户**：直接双击 `run.bat` 启动即可。

**手动启动**：
```bash
mvn clean package
mvn javafx:run
```

启动后屏幕底部会出现悬浮字幕窗口，右键可打开菜单。

## 📖 使用说明

1. **开始录制**：按 `F9` 或双击字幕窗口开始录制（默认全屏）
2. **选择区域录制**：右键 → 选择录制区域，拖拽鼠标画框选择要录制的屏幕范围
3. **暂停录制**：录制过程中按 `F10` 暂停/恢复
4. **停止录制**：再次按 `F9` 停止录制
5. **查看文件**：录制完成后右键 → 打开录制文件目录，即可看到MP4视频和SRT字幕文件

## 🎯 识别准确率优化说明

v0.3.1版本对识别准确率做了多项优化：

1. **端点检测优化**：将句尾静音判定从0.5秒延长到1秒，减少句子中间停顿误判断句
2. **音频缓冲优化**：增大音频采集缓冲区，减少丢帧和爆音
3. **结果去抖算法**：临时结果相似度过滤，减少字幕闪烁跳变
4. **后处理纠错**：自动过滤"嗯/啊/呃"等无意义语气词
5. **单字过滤**：过滤长度≤1的识别结果，减少误识别
6. **自动加标点**：句子结束自动补全句号，字幕更自然
7. **静音断句**：连续静音1.5秒以上自动分段
8. **模型自动查找**：自动识别models目录下的标准版/轻量版模型，优先使用准确率更高的标准版

> 💡 **进一步提升识别率的建议**：
> - 尽量使用标准版模型（1.3GB），比轻量版准确率高30%以上
> - 录制时保持环境安静，麦克风距离嘴部20-30cm
> - 说话语速平稳，吐字清晰
> - 可以在系统声音设置中适当调大麦克风音量，避免声音太小识别不到

## 📁 输出文件说明

录制结束后，在 `recordings/` 目录生成两个文件：

- `recording_YYYYMMDD_HHMMSS.mp4` - 录屏视频文件，包含麦克风音频，H.264/AAC编码
- `recording_YYYYMMDD_HHMMSS.srt` - 标准SRT格式字幕文件

可以用任何支持字幕的播放器（PotPlayer/VLC/MPC-HC等）直接加载SRT字幕，或者使用FFmpeg将字幕烧录进视频：

```bash
ffmpeg -i recording.mp4 -vf subtitles=recording.srt output_with_subtitle.mp4
```

## 🔧 常见问题

**Q: 快捷键F9/F10没反应？**  
A: Windows下可能需要以管理员身份运行，Linux/macOS需要开启辅助功能权限。或者可以双击字幕窗口开始录制，右键操作所有功能。

**Q: 识别出来很多错字怎么办？**  
A: 请下载标准版大模型（1.3GB），识别准确率比轻量版高很多。同时保持麦克风音量适中，环境安静。

**Q: 启动时提示找不到模型？**  
A: 确认模型解压到了models目录，且文件夹名字正确（应包含conf子文件夹）。右键字幕窗口 → 语音模型设置可以查看详细路径。

**Q: 字幕窗口挡住内容了怎么办？**  
A: 可以直接拖拽移动位置，或者右键 → 窗口透明度调低，或者右键 → 字体大小调整字号。
